تطبيق Desktop (Electron)

1) ثبت Node.js 18 أو أحدث: https://nodejs.org
2) فهاد المجلد:   npm install
3) للتجريب:       npm start
4) باش تصايب ملف التثبيت (.exe):   npm run dist
   النتيجة فمجلد dist/ (دير هادشي على ويندوز)
5) للاختبار:                      npm test

المعطيات كتتحفظ فملف حقيقي:
   Documents/CentreData/data.json
ونسخة احتياطية عند كل تعديل فـ:
   Documents/CentreData/backups/   (كتبقى محفوظة حتى تحذفها بيدك)

# Centre — تسيير مراكز الدعم المدرسي

تطبيق مكتبي **(Electron)** خفيف، يعمل **بدون إنترنت**، لتسيير مركز الدعم المدرسي واللغات والتكوين: التلاميذ، التسجيلات، الحضور، الأداءات، الوصولات، والتعريفة — مع تخزين محلي آمن ونسخ احتياطي تلقائي.

## الميزات

### 📊 لوحة القيادة
- إحصائيات شهرية: عدد التلاميذ، التسجيلات النشطة، المبلغ المقبوض، والباقي المستحق.
- تنبيهات الأداءات القريبة (3 أيام أو أقل) والمتأخرة.
- لائحة التلاميذ الذين عليهم أداءات مستحقة.
- توزيع التلاميذ حسب المادة والمستوى.
- رصد الغيابات المتكررة (3 مرات أو أكثر في 30 يوماً).

### 👨‍🎓 التلاميذ
- إضافة وتعديل وحذف ملفات التلاميذ (الاسم، الهاتف، المستوى، ملاحظات).
- بحث فوري بالاسم أو الهاتف أو النشاط.
- تسجيل التلميذ في عدة أنشطة بثمن شهري وتاريخ بداية مستقل.
- إيقاف/تفعيل التسجيل، وتعديل الثمن وتاريخ البداية.
- سجل كامل: التسجيلات، الأداءات، الوصولات، والحضور.

### 🗓️ الحضور
- تسجيل الحضور والغياب حسب النشاط والتاريخ.
- استعراض سجل الحضور لكل تلميذ.

### 💰 الأداءات
- تسجيل الأداء لشهر واحد أو عدة أشهر.
- حساب المبلغ تلقائياً حسب التعريفة وعدد الأشهر.
- متابعة ما تبقّى على كل تسجيل.
- إخراج **وصل أداء** قابل للطباعة.

### 🏷️ التعريفة
- تعريفة شهرية لكل مادة ونشاط.
- إضافة مواد جديدة لكل نشاط (دعم مدرسي، لغات، تكوين) مع تحديد ثمنها.
- المواد الأساسية ثابتة، والمواد المضافة تظهر مباشرة في نموذج التسجيل.

### 💬 رسائل
- إنشاء رسائل تذكير جاهزة للتلاميذ المعنيين بالأداءات.
- إرسال مباشر عبر **واتساب** (`wa.me`) مع تحويل أرقام الهاتف المغربية تلقائياً إلى الصيغة الدولية.

### ⚙️ إعدادات المركز
- تغيير اسم المركز ورفع الشعار (يظهر في الواجهة والوصل المطبوع).
- تصدير/استيراد نسخة كاملة من المعطيات (JSON) مع تحقق صارم قبل الاسترجاع.
- استرجاع النسخ الاحتياطية المحلية من داخل التطبيق.
- وضع ليلي تلقائي حسب نظام التشغيل، وواجهة عربية RTL بخط Cairo.

## التقنيات

| الطبقة | التقنية |
| --- | --- |
| الإطار | Electron 33 |
| الواجهة | HTML / CSS / JavaScript خالص (بدون إطار عمل) |
| العمليات الخلفية | Node.js (CommonJS) |
| التخزين | ملف JSON محلي مع كتابة ذرية |
| الترخيص | Ed25519 (توقيع غير متصل + ربط بالجهاز) |
| الاختبارات | `node --test` (20 ملف اختبار) |
| التغليف | electron-builder (NSIS + ASAR) |

> التطبيق لا يستعمل أي مكتبة إنتاجية خارج Electron، ولا يقوم بأي اتصال بالشبكة. سياسة CSP صارمة تمنع `connect-src` تماماً.

├── runtime-paths.js         # مسارات التشغيل وعزل بيئة الاختبار

## تخزين المعطيات والنسخ الاحتياطي

- تُحفظ المعطيات في ملف حقيقي:

  ```
  Documents/CentreData/data.json
  ```

- تُحفظ **نسخة احتياطية قبل كل تعديل** في:

  ```
  Documents/CentreData/backups/
  ```

  وتبقى محفوظة إلى أن تحذفها يدوياً.

- الكتابة تتم بشكل ذرّي (ملف مؤقت ثم إعادة تسمية) لتفادي تلف الملف عند انقطاع الكهرباء أو الإغلاق المفاجئ.
- يُنصح بعدم وضع مجلد المعطيات داخل مجلد متزامن مع OneDrive؛ التطبيق يعرض تحذيراً في هذه الحالة.
- يمكن أيضاً تصدير نسخة يدوية (JSON) واستيرادها لاحقاً من تبويب **لوحة القيادة**.

## الأمان والترخيص

- **الترخيص غير متصل بالإنترنت**: يُوقَّع الترخيص خارجياً بـ **Ed25519**، والتطبيق يحتوي فقط على المفتاح **العمومي** للتحقق.
- **ربط بالجهاز**: يعتمد على تجزئات `machineGuid` و`smbiosUuid` (وسيطياً رقم قرص النظام)، ولا تُخزَّن المعرّفات الخام في الترخيص.
- **فشل مغلق**: لا يعمل التطبيق إذا لم يكن الترخيص صالحاً أو إذا لم يُكوَّن المفتاح العمومي للإنتاج.
- **عزل الواجهة**: `contextIsolation` و`sandbox` و`nodeIntegration: false`، مع تعريض واجهة IPC محدودة فقط.
- **CSP صارمة** تمنع أي اتصال شبكي أو تحميل موارد خارجية.
- **قائمة بيضاء للتغليف**: `build.files` في `package.json` تحدّد الملفات المشمولة فقط، وتستبعد المفاتيح والشهادات وأدوات الإصدار والاختبارات.

> ⚠️ **قبل الإصدار:** يجب إدخال المفتاح العمومي الحقيقي في `trusted-keys.js`. حالياً التطبيق يفشل عمداً حتى يتم تكوينه.

## بناء ملف التثبيت

على **Windows**:

```bash
npm run dist
```

النتيجة تكون في مجلد `dist/` (مثبت NSIS بصيغة `.exe`).

ملاحظات:
- الحزمة تُبنى بصيغة **ASAR** مع قائمة ملفات صريحة.
- **توقيع الكود غير مُكوَّن بعد**؛ قد تظهر تحذيرات SmartScreen إلى أن تُضاف شهادة توقيع.
- يجب فحص أي حزمة حقيقية بقواعد `test/packaging-policy.test.js` قبل النشر.

## أدوات المالك

مجلد `tools/` يحتوي أدوات إصدار التراخيص (توليد الترخيص، توقيعه، وربطه بالجهاز). هذه الأدوات:

- مخصّصة **للمالك فقط**،
- تُستعمل على جهاز توقيع **غير متصل بالإنترنت**،
- **لا تُشمَل أبداً** في حزمة التطبيق،
- لا تحتوي على أي مفتاح خاص داخل هذا المستودع.

راجع [`tools/README.md`](tools/README.md) لمعرفة سير العمل الكامل.

## ملاحظات وحدود معروفة

- لا توجد حالياً واجهة تفعيل داخل التطبيق؛ الترخيص يُثبَّت عبر مسار التخزين المخصص.
- لا يوجد سيرفر ترخيص أو إلغاء ترخيص عن بعد (التحقق محلي بالكامل).
- ربط الجهاز إجراء ردعي وليس حماية مطلقة.
- التطبيق موجّه أساساً لبيئة Windows.

## الترخيص

هذا المشروع **خاص** ولا يتضمن ملف ترخيص مفتوح المصدر. جميع الحقوق محفوظة للمالك. يُمنع إعادة التوزيع أو الاستعمال التجاري دون إذن كتابي مسبق.
